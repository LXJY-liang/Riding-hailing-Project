# Vit上游标签与基础特征

本目录收纳新版 Vit 预训练使用的历史上游信息。

## 1 司机轨迹Oracle构造

### 数据依赖

- 历史供给参考路径直接读取：
  `3 随机变量分位数预测/3 Sit构建/output/S_it_historical_reference.parquet`。
- 该文件由 `3 Sit构建/3 学习U分布.py` 在学习 U 分布时同步生成，覆盖
  2024-06-01 至 2024-06-30，共 801 个区域。
- `input/active_od_base.parquet`：轨迹模拟使用的历史成交 OD、参考价格、司机成本和行程时间。
- `input/region_mapping.csv`：区域 ID 与数值索引映射。

Vit目录不再保存或重建 Sit 副本。

### 新版标签流程

1. `2 构建司机未来价值Vit分布.py`
   - 对 2024-06-01 至 2024-06-24 的每个区域—15分钟开始状态模拟1000条未来4小时轨迹；
   - 每条轨迹按历史成交 OD、参考价格、司机成本和行程时长推进；
   - 无历史成交订单时司机在原区域等待，抽到历史成交订单后随订单转移到目的地；
   - 不额外模拟司机拒单，历史成交订单的司机净收益可为负，因此Vit的低分位数允许小于0；
   - 直接从1000个累计净收益样本计算
     `q0.005、q0.01、...、q0.99、q0.995` 共101维标签；
   - 输出 `output/1 司机轨迹Oracle构造/V_it_labels_101.parquet`。
2. `3 检查司机未来价值Vit分布.py`
   - 检查行数、日期、区域覆盖、有限值和101维分位数单调性；
   - 统计包含负净收益分位数的状态，但负值本身不会导致检查失败。

运行顺序：

```bash
./.venv/bin/python "4 Vit预训练模型/0 上游标签与基础特征/1 司机轨迹Oracle构造/2 构建司机未来价值Vit分布.py" --overwrite
./.venv/bin/python "4 Vit预训练模型/0 上游标签与基础特征/1 司机轨迹Oracle构造/3 检查司机未来价值Vit分布.py"
```

### Sit文件的区别

- `S_it_historical_reference.parquet`：6月1—30日的一条确定性历史参考供给路径，含事后历史信息，供Vit监督标签使用。
- `S_it_weekday7_unconstrained_quantiles.parquet`：6月11—30日基于500条随机路径得到的供给分位数，服务于SAC随机环境。

二者都由Sit模块产生，但用途与日期范围不同。历史参考路径不能直接作为SAC在时点t的状态。

### 1000条轨迹与101维分位数

1000条轨迹用于计算101个线性经验分位点。q0.005与q0.995分别位于样本两端约第5个
顺序统计量附近，比64条轨迹稳定得多，但极端尾部仍会比中部分位数更易波动。
按64与500条轨迹的实测速度估算，全量1000条轨迹预计约20至24分钟。

旧供给代理、旧19维标签、19维到101维插值脚本和旧分割标签均已删除。
Prompt文本化和全量模型训练已由`1 数据准备`中的6个连续脚本接入新版标签。

## 2 历史司机收益基础特征

- `1 司机历史收益特征构造.py`：从订单级价格、里程和时长构造历史司机收益特征。
- 所有滑动收益特征都先滞后一个时段；异常值已改为固定业务边界，不再用会引入未来信息的全月分位数截尾。
- `2 Vit基础特征构造.py`：合并区域、时间、天气和历史司机收益。
- `output/2 历史司机收益基础特征/2 Vit基础特征构造（结果）.parquet`：现有Vit Prompt构造的基础输入。
