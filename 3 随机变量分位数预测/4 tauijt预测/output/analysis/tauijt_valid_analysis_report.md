## 5. 简要结论

- 所有101个分位数均无交叉，且没有负值，说明分位数输出的结构约束生效。
- 50%/80%/90%/98% 区间的实际覆盖率均略高于理论值，预测区间整体偏保守，但偏差较小。
- RMSE 高于 MAE，且高分位绝对误差明显变大，说明极端长服务时间仍是主要误差来源。
- 当前报告仅来自验证集；在模型和参数固定后，应在从未参与调参决策的测试集上运行相同评估，作为最终泛化结论。
