# 任务 8：服务器训练说明

正式 SAC 默认进行 20,000 次反事实组收集并更新网络，不调用 Qwen 或任何大语言模型。
反事实收益主要在 CPU 上计算，神经网络更新使用 GPU，完整主实验预计需要数小时。
建议先在服务器完成一次 smoke test，再用 GPU 和 tmux 启动正式训练。

## 1. 确认输入文件

如果希望在服务器从头重建全部派生数据，项目中需要存在：

- `6 离线SAC训练/1 数据准备/output/active_od_base.parquet`
- `6 离线SAC训练/2 Sit重构/output/S_it_historical.parquet`
- `6 离线SAC训练/3 Vit准备/output/V_it_distribution.parquet`
- `6 离线SAC训练/4 离线SAC模型/output/offline_sac_state.parquet`

如果服务器没有这些派生文件，就按根目录 `README.md` 的准备顺序重建，此时还需要上传
`1 数据清洗` 中相应的上游文件。若本地派生文件已经生成，正式训练的最小数据输入只有：

- `6 离线SAC训练/3 Vit准备/output/V_it_distribution.parquet`
- `6 离线SAC训练/4 离线SAC模型/output/offline_sac_state.parquet`

因此，推荐直接上传整个 `6 离线SAC训练` 文件夹；这种情况下无需上传 `1 数据清洗`。

## 2. 先做服务器 smoke test

```bash
cd "/root/autodl-tmp/Riding hailing_Project"
python "6 离线SAC训练/4 离线SAC模型/5 训练离线SAC模型.py" --smoke --run-name server_check
```

看到“保存新的最佳模型”且退出码为 0，说明数据、CUDA/PyTorch 和奖励计算链路正常。

## 3. 主实验 gamma_SAC=0.99

```bash
cd "/root/autodl-tmp/Riding hailing_Project"
chmod +x "6 离线SAC训练/4 离线SAC模型/7 在服务器启动训练.sh"
RIDING_HAILING_PROJECT_ROOT="/root/autodl-tmp/Riding hailing_Project" \
SAC_GAMMA=0.99 \
SAC_RUN_NAME=gamma099 \
SAC_AUTO_SHUTDOWN=1 \
bash "6 离线SAC训练/4 离线SAC模型/7 在服务器启动训练.sh"
```

`SAC_AUTO_SHUTDOWN=1` 是默认设置：训练成功或异常退出后，脚本先保存日志，再等待60秒
调用 AutoDL 的 `/usr/bin/shutdown`。因此本地电脑关机或 SSH 断开不会影响远程训练，
远程训练进程结束后实例会自动关机。仅在调试且希望保留开机状态时设置为0。

SSH 断开不会终止 tmux 中的训练。查看方式：

```bash
tmux attach -t offline_sac_gamma099
```

按 `Ctrl-b`，再按 `d` 可退出 tmux 但保持训练。脚本打印的日志路径也可以用
`tail -f 日志路径` 查看。

## 4. gamma_SAC=0 消融

主实验完成后独立启动第二个实验：

```bash
RIDING_HAILING_PROJECT_ROOT="/root/autodl-tmp/Riding hailing_Project" \
SAC_GAMMA=0 \
SAC_RUN_NAME=gamma000 \
bash "6 离线SAC训练/4 离线SAC模型/7 在服务器启动训练.sh"
```

两个实验分别写入 `output/model/gamma099/` 和 `output/model/gamma000/`，不会相互覆盖。

## 5. 先在验证集只查看 SAC 价格与补贴

默认不运行任何比较基线，也不会访问测试集：

```bash
python "6 离线SAC训练/4 离线SAC模型/6 评估离线SAC策略.py" \
  --split valid \
  --mode sac_only \
  --checkpoint "6 离线SAC训练/4 离线SAC模型/output/model/gamma099/best_offline_sac.pt" \
  --output-tag gamma099
```

逐 OD 结果写入 `output/valid_policy_sac_only_gamma099.parquet`，汇总指标写入
`output/log/evaluation_metrics_valid_sac_only_gamma099.json`。只有明确需要比较三个简单
基线时才改为 `--mode simple_baselines`；`--mode all` 还会运行极慢的二维网格搜索。
测试集必须显式传入 `--split test`，应在模型与分析规则确定后再使用。

当前训练脚本按验证集最佳结果保存模型。tmux 可以防止 SSH 断开，但服务器进程被强制
终止后，本版本不会恢复内存回放池，因此应重新启动该 run；不要把 smoke 检查点当成
正式模型。
